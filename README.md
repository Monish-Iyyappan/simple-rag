<p align="center"><b>Simple RAG</b>: a retrieval-augmented generation system built by hand in Java and Python, sharing one MongoDB Atlas collection.</p>

<br>

## What works so far

- Java (Spring Boot): `/ingest` uploads a `.txt` file, `/ask` answers from your documents and returns the source chunks
- Python: command-line `ingest` and `ask`
- A simple web page to ask questions
