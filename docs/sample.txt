Retrieval-Augmented Generation, or RAG, lets a language model answer questions using your own documents. First, the documents are split into small chunks. Each chunk is converted into an embedding, which is a list of numbers that represents its meaning. The embeddings are stored in a database such as MongoDB Atlas. When a user asks a question, the question is also converted into an embedding. The database then finds the chunks whose embeddings are closest to the question. Those chunks are added to the prompt, and the language model writes an answer based only on that context. This reduces made-up answers and lets the model use information it was never trained on.
